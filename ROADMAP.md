# Roadmap

This roadmap is a planning document, not a promise of delivery dates.

## Foundation

- [x] Publish the single-page application with configurable letterhead.
- [x] Add project documentation, licence and contribution templates.
- [ ] Validate existing calculations with documented fictional test cases.
- [ ] Add a repeatable browser-based smoke-test suite.

## Reliability and usability

- [ ] Review all assessment formulas and expose assumptions next to relevant fields.
- [ ] Improve validation and error messages for incomplete or inconsistent data.
- [ ] Improve mobile table editing and print pagination.
- [ ] Add accessibility checks for labels, keyboard navigation and contrast.
- [ ] Add import/export format versioning and recovery tests.

## Security and architecture

- [ ] Review third-party dependencies and pin versions.
- [ ] Evaluate a secure optional backend for multi-user OCR without exposing shared API keys.
- [ ] Add a clear data-retention and deletion workflow.
- [ ] Evaluate encryption for locally stored records and exported backups.

## Community and extensibility

- [ ] Document insurer-specific configuration points.
- [ ] Separate jurisdiction-specific rules from generic application logic.
- [ ] Add synthetic sample datasets and reproducible examples.
- [ ] Establish a process for reviewing calculation and regulatory changes.
