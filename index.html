Auto-fill Assessment from Documents (OCR)
Upload the repair Estimate and/or final Bill (scanned image, downloaded PDF, or a photo — either works) and Claude will read the line items and add them to the Labour and Parts tables below as new rows. Estimated and Billed amounts are extracted as the taxable (pre-GST) amount for each line, not the tax-inclusive total — GST is applied separately by this tool, so this avoids double-counting tax. Uses the same API key entered above. This adds rows on top of what's already there rather than replacing them — review, adjust Job/Category and Dep% as needed, and remove anything mis-read.
Assessment Sheet — Labour Charges
Yes = assessment calculated without depreciation (full Assessed value carried to After Dep.). No = depreciation applied per age-slab / material rules below.
Assessed is entered manually (defaults to the Billed amount when left blank — edit to reflect the surveyor's agreed figure). Dep % auto-suggests on Paint jobs as a flat effective rate (12.5% for Private, 56.25% for Commercial IMT-23 — derived from the India Motor Tariff 25:75 material/labour split with 50% material depreciation) and 50% on plain IMT23 jobs (the IMT-23 endorsement's 50%-of-assessed payout rule); if NIL Depreciation Cover above is set to Yes, all of these are waived to 0%. Other job types stay 0% unless entered manually. All auto-suggested values remain editable. After Dep. = Assessed × (1 − Dep%). Tax is calculated on After Dep. at the row's GST%. Net Amt = After Dep. + Tax. Hover over After Dep. on a paint row for the calculation detail.

Assessment Sheet — Spares
Depreciation auto-fills from Registration Date → Date of Accident against the vehicle age depreciation schedule (not exceeding 6mo Nil, 6mo–1yr 5%, 1–2yr 10%, 2–3yr 15%, 3–4yr 25%, 4–5yr 35%, 5–10yr 40%, exceeding 10yr 50%) for the "Normal Depreciation" and "IMT23 Metal" categories, applied to the Assessed amount (not Billed). "Plastic/Rubber", "FRP" and "IMT23 Plastic" use the flat 50% material rule regardless of age. The two IMT23 categories additionally apply the IMT23 endorsement's 50%-of-normal-assessed-value payout rule. If NIL Depreciation Cover above is set to Yes, depreciation is waived on all non-IMT23 categories. All auto-filled values remain editable — override for policy-specific terms.
