# Changelog

## 0.1.0 — Initial public repository preparation

- Added project documentation, MIT licence, contribution guidance and security policy.
- Replaced personal surveyor identity, contact and licence details with configurable letterhead settings.
- Removed embedded personal signature images from report templates.
- Removed API-key persistence entirely: users enter their own key, which stays in page memory only and is cleared when the page is closed or the user selects Clear.
- Documented local browser storage, OCR data transmission and current project limitations.
